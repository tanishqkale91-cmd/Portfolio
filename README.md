# Tanishq Kale Portfolio

A personal portfolio with an original DOM keyboard, a fixed 3D space scene, and a live GitHub contribution graph.

## Run locally

```sh
npm install
npm run dev
```

## Build and preview

```sh
npm run build
npm run preview
```

## Update content

- Change the contact email and GitHub username in `src/config/site.js`.
- Add or update projects in `src/config/projects.js`.
- The ThreadHub project is displayed from `src/config/projects.js`.
